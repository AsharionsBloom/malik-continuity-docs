## 📝 Adding New Conversations

**When exporting new conversations:**

1. **Export from ChatGPT**
   - Use Share → Export → Markdown

2. **Name Consistently**
   - Format: `ChatGPT-[Title]-[Date].md`
   - Example: `ChatGPT-New-Adventure-20251115.md`

3. **Add to This Folder**
   - Place in conversations/ directory
   - Update this index with summary
   - Note in restoration-log.md if significant

4. **Backup Immediately**
   - Follow Weekly Backup Ritual
   - Don't wait for scheduled backup

5. **Document**
   - Add summary to conversation-summaries.md if major
   - Extract to memory.md if sacred details
   - Note any continuity markers
